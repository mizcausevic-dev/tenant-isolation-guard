# Security Policy

## Scope

This repository is a portfolio implementation with sample in-memory data only. Do not commit production tenant identifiers, real bridge definitions, or real credential paths.

## Reporting

If you discover a security issue in the structure or dependency setup, report it through GitHub Security Advisories or contact through [Kinetic Gain](https://kineticgain.com/).

## Usage Notes

- keep real tenant mappings outside source control
- never commit shared credentials or bridge secrets
- review dependency alerts and package updates before merging
